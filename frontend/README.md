# CreatorPulse — Frontend (Module 1 UI)

React + Vite single-page app for the Content Creator Growth Platform (Module 1: Web Service Core).

- Runs on `http://localhost:5173`
- Talks to the Spring Boot backend at `http://localhost:8080/api` (see `src/api.js`)
- Pages: login, signup, forgot/reset password, onboarding (creator profile), dashboard, edit profile

```bash
npm install
npm run dev
```

See the repository root `README.md` for the full setup, architecture, and API reference.
